# UI 風格改版計畫

參考：Dribbble 上 Anastasia Samarska 的單字 App 概念圖（藍紫色、柔和、圓角）。**只參考風格方向**（配色、形狀、層次），版面與插圖不照抄，圖示與插圖由我們自己製作。

狀態：A–F 全部完成（2026-11-10）。2026-11-14 改成 Material 3 風格，見第 8 節（第 2–4 節的色票與字體已被取代）。每個階段完成都截圖（375px 手機、桌面、深色模式）並跑 tsc / lint / test 再 commit。

---

## 1. 參考圖的風格拆解

| 面向 | 參考圖的做法 | 目前的 Moji |
|---|---|---|
| 主色 | 長春花藍（periwinkle），偏紫的中藍 | 墨綠 `#2f5d50` |
| 背景 | 近白帶一點藍；啟動頁是淡藍漸層 | 米白 `#fbfaf7` |
| 區塊 | **淡藍色填色**的卡片，幾乎不用邊框 | 白卡片 + 灰邊框 |
| 圓角 | 卡片約 14–16px、按鈕全圓（膠囊） | 10px |
| 字體 | 圓潤的幾何無襯線，標題用中等粗細而非粗體 | Geist，標題粗體 |
| 導航 | 手機底部分頁列（首頁、練習、搜尋、個人），選中的圖示實心藍 | 頂部兩列文字導航 |
| 首頁 | 問候語「Hi, Ann!」＋單字本格狀磚塊 | 搜尋框＋功能介紹 |
| 測驗 | 大的題目卡（淡藍）＋膠囊選項，選中變實心藍 | 翻卡＋四個評分按鈕 |
| 氣氛 | 插圖（彩色對話泡泡）、輕鬆友善 | 簡潔、偏工具感 |

## 2. 設計 token（`src/app/globals.css`）

整套顏色只改 CSS 變數，shadcn 元件與所有頁面會一起換色。主色選 `#4263eb`：比參考圖略深一點，白字在上面的對比度約 5:1（符合 WCAG AA）；參考圖那種較淺的藍 `#6b8cf0` 當裝飾色（插圖、漸層、圖示）。

| 變數 | 淺色（新） | 深色（新） | 用途 |
|---|---|---|---|
| `--background` | `#f5f7ff` | `#12152a` | 頁面底色 |
| `--foreground` | `#1f2440` | `#e8ebfa` | 主要文字（深藍灰，不用純黑） |
| `--card` | `#ffffff` | `#1b1f38` | 白色卡片 |
| `--primary` | `#4263eb` | `#8fa6ff` | 按鈕、連結、選中狀態 |
| `--primary-foreground` | `#ffffff` | `#12152a` | |
| `--accent` | `#dfe6fd` | `#26305e` | **淡藍磚塊**（單字本、題目卡、選項） |
| `--accent-foreground` | `#2a3f9e` | `#c9d4ff` | |
| `--muted` / `--secondary` | `#eef2fe` | `#20253f` | 次要底色、分頁列底 |
| `--muted-foreground` | `#646b8a` | `#9aa2c4` | 次要文字 |
| `--border` / `--input` | `#dde3f7` | `#2c3356` | 只在必要處使用 |
| `--radius` | `1rem` | | 卡片 16px，按鈕另用 `rounded-full` |
| 新增 `--brand-soft` | `#6b8cf0` | `#6b8cf0` | 插圖、漸層等裝飾 |

- 例句的螢光標記 `--mark`、複習評分色（`--again` 等）保留，只微調成和藍色搭配的色調。
- PWA 的 `theme_color`、`themeColor`、App 圖示改成藍色系。

## 3. 字體

- 英文改用 **Nunito**（圓潤、有多種粗細），透過 Next.js 內建的 `next/font/google` 載入，**不需要新增 npm 套件**；build 時下載字型並由自己的網域提供。
- 中文維持系統字型（PingFang TC／Noto Sans TC／微軟正黑體）。Nunito 沒有中文字，會自動接到系統字型。
- 標題由 `font-bold` 改為 `font-semibold`，整體更柔和。
- 音標、程式碼維持等寬字型。

## 4. 元件層級的調整

| 元件 | 改動 |
|---|---|
| 按鈕 | 主要按鈕改膠囊形（`rounded-full`）；次要按鈕用淡藍底取代外框 |
| 卡片／列表 | 去掉灰邊框，改白卡片＋極淡陰影，或淡藍填色 |
| 搜尋框 | 膠囊形、較高（48px）、左側放大鏡圖示 |
| 分頁（釋義／相似） | 改成膠囊分段控制（淡藍底、選中白底），取代底線 |
| 晶片（單字本篩選） | 淡藍底膠囊，選中實心藍白字 |
| 熟悉度面板、美式／英式切換 | 沿用新分段控制樣式 |
| 對話框 | 圓角加大到 20px |

## 5. 頁面層級的調整

### 5.1 頁首導航
- **不做底部分頁列**，維持目前的頂部導航（手機兩列、桌面一列），只換樣式：
  - 頁首底色改白、去掉底線改極淡陰影
  - 導航項目選中時加淡藍膠囊底（標出目前在哪一頁）

### 5.2 首頁
- **維持搜尋為主**（登入與否都一樣）：搜尋框＋三張功能介紹卡片，不改成儀表板。
- 換樣式：搜尋區改成淡藍漸層的大圓角卡片（含副標），白色膠囊搜尋框浮在上面。
- 功能卡片：實作時發現淡藍填色和漸層搜尋區太像、沒有層次，改成白卡片＋淡藍圓底圖示（查字／收藏／複習）。
- 插圖：暫不做，之後若要加再討論。

### 5.3 管理單字本
- 列表改成 2 欄淡藍磚塊（同首頁），編輯／匯出／刪除收進 ⋮ 選單。
- 「全部收藏」磚塊固定在第一格，顏色稍深區分。
- 首頁不放單字本磚塊（維持搜尋為主），只改管理單字本頁。

### 5.4 單字頁
- 標題列右側的收藏／筆記／熟悉度按鈕改成圓形淡藍底。
- 釋義、例句等區塊改成白卡片分組，區塊標題改淡色小字。
- 分頁改膠囊分段控制。

### 5.5 複習頁
- 題目卡：大的淡藍卡片，單字置中放大。
- 四個評分按鈕改膠囊形，維持各自顏色（再來一次／困難／良好／簡單）但改淡色底＋深色字，按下時實心。
- 進度改成上方細進度條（參考圖的 `1/150`）。
- 參考圖的**四選一測驗**是新的複習模式，不在這次改版範圍，列為之後的功能。

### 5.6 其他頁面
登入／註冊、帳號、設定、筆記、我的單字列表：套用新 token 與元件樣式即可，版面不大改。

## 7. 已定案的決定（2026-11-10）

1. 手機底部分頁列：**不做**，維持頂部導航，只換樣式。
2. 字體：英文改 **Nunito**，中文維持系統字型。
3. 首頁：**維持搜尋為主**，不改儀表板。
4. 插圖：暫不做。
5. 熟悉度顏色：「低」改**紫色**（無 = 灰、低 = 紫、中 = 黃、高 = 綠）。
6. 深色模式：先照第 2 節的深藍色系，實作後看截圖再調。

## 8. 第二次改版：Material 3（2026-11-14）

第一版（長春花藍、Nunito、白卡片＋柔和陰影、淡藍漸層）看起來太像「AI 生成的模板」，改成 Google 的 Material 3 設計規則。**不換元件庫**（MUI 會和 Tailwind 打架、Material Web 已停止積極開發），保留 shadcn，只改 token 與元件樣式。主色沿用 `#4263eb`。

| 面向 | 改成 |
|---|---|
| 色彩 | M3 色彩角色：`background` = surface、`card` = surface container、`muted` = surface container high、`secondary`／`accent` = secondary container、`border` = outline variant、`input` = outline。中性色帶一點藍紫（由主色推出） |
| 區塊層次 | 靠表面色階深淺區分，**不用陰影也不用邊框**（`--surface-shadow: none`）；清單項目之間用 2px 背景色間隔取代分隔線 |
| 字體 | 英文 **Roboto Flex**（`next/font/google`），中文系統字型；首頁大標題用一般粗細 |
| 圓角 | 固定的 M3 尺度：4（輸入框）、8、12、16（卡片）、28（對話框、展開的搜尋清單）；按鈕全圓 |
| 按鈕 | filled（`default`）、filled tonal（`secondary`、`soft`）、outlined（`outline`，細框＋主色字）、text（`ghost`）；hover 疊 8% 前景色、按下 12%（state layer），不再有按下位移 |
| 分頁 | M3 primary tabs：整排分隔線，選中文字變主色＋下方 3px 圓頭指示條 |
| 分段控制 | 美式／英式、熟悉度改成 M3 segmented button：外框膠囊，選中格填 secondary container |
| 頁首 | 與頁面同底色、沒有陰影（M3 top app bar）；導航選中用 secondary container 膠囊 |
| 首頁 | 拿掉漸層卡片，改成大標題＋56px 高的膠囊搜尋列（surface container high） |

待定：手機是否改成底部導航列（M3 navigation bar）。
